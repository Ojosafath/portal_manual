GIG ELD PORTAL — BILINGUAL OPERATIONS GUIDE

CONTENTS
- index.html: the bilingual interactive guide (English / Spanish)
- assets/: screenshots extracted from the supplied 7-page GIG ELD Portal PDF

PUBLISH WITH GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository.
3. Choose Add file > Upload files.
4. Upload index.html and the complete assets folder (do not upload only the ZIP).
5. Commit the files to the main branch.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select Branch: main and Folder: /(root), then Save.
9. Wait for deployment and use Visit site.

ADD TO GODADDY
1. Copy the published GitHub Pages URL.
2. In GoDaddy Websites + Marketing, open the MANUAL page.
3. Add a button or text link to the published guide URL.
4. Suggested button label: GIG ELD PORTAL GUIDE.
5. Save and publish the GoDaddy site.

NOTES
- The guide includes English and Spanish language buttons.
- The portal menu names and field labels are preserved in English as shown in the source manual.
- Screenshots are extracted from the user-provided PDF.
- This is a static website; it does not connect to or control the live GIG ELD Portal.
- Do not add passwords, customer information, driver personal data, or other confidential information to the public repository.
